## 判断

现有平台已经有可保留的改进内核：冻结条件、失败证据、一个局部候选、静态检查、独立验证、人工采用、版本恢复。
当前实现属于 RSI 思想下的 Skill 改进平台；尚未实现优化器自身递归改进。
下一步最有价值的是让每一轮理解上一轮的有效经验，并把“问题—修改—验证—决定”变成用户主线。
保留单轮内核，先减少界面和决策成本，再考虑有预算与停止条件的连续迭代。

## RSI 闭环只补四项

### 一轮只围绕一个可验证的问题

在工作台给出一行本轮目标，例如“修复增强类型映射，禁止路由回归”。
可从失败类别选择，不要求用户填写长计划。
平台已有 diagnosis/hypotheses/expected_effect 等信息，应将“为什么这样改”直接连到案例、文件变更和验证结果。

### 下一轮能继承有效经验

当前候选上下文主要使用本轮失败及当前 Skill，已有运行历史尚未形成明确的策略反馈。
只补充一小段结构化经验：改过什么、是否改善、失败原因、适用版本、来源轮次。
优先避免重复提交相同无效补丁，不引入知识图谱或独立记忆管理页面。
经验来自优化集与实际修改；验证/最终测试样本内容继续隔离，不能随经验摘要泄漏给优化器。

### 采用后继续，退步能恢复

平台已经支持通过版本记录设为当前来恢复旧版本，不需要新建回滚系统。
在应用完成的同一位置增加“继续下一轮”和“恢复应用前版本”，使用现有版本接口即可。
若以后增加连续运行，设置轮数与总预算上限；无改善、补丁重复、回归或预算耗尽时停止。
验证集会被多轮选择间接使用，不能把反复调优过的验证集当作新的独立证据；最终测试仍用于阶段验收。

### 让真实纠正进入回归集

失败案例旁提供“纠正预期并加入回归”，发布为新的数据集版本。
来源清晰地进入优化/回归数据，避免直接污染验证与最终测试内容。
这比扩展更多抽象自进化模块更直接地把用户反馈接回改进循环。

## 前端减法

### 工作台：只突出下一步与本轮决定

目前概览页在主按钮、配置完整性、首次引导与运行列表中重复呈现状态。
合并为一张状态驱动主卡片：未配置→补配置；缺兼容基线→运行基线；运行中→看进度；有候选→决定是否采用。
已有历史、模型、数据集信息保留一行摘要，需要时展开。

当前结果页在 1200×726 浏览器中高约 2566px，“应用候选”按钮位于约 2429px 处。
将结论与下一步置顶，然后展示验证集改善、回归数量、修改原因；案例与差异紧随其后，原始日志和完整规则按需查看。
主指标使用联合通过率，路由与入参作为紧凑的分项；同时显示独立案例数与重复次数，避免将重复次数误当样本数量。

### 导航：先最小改版，随后收敛到三个入口

- 立即可做：保留当前页面，移动结论、折叠重复快照、统一主按钮与术语，不重写前端框架。
- 目标结构：优化工作台、Skill、测试集；连接与运行设置作为设置入口，迭代历史从工作台打开。
- 原有环境与版本能力保留；减少顶层入口，不删除其底层实体。

### 模型配置：保留两个必要角色

默认显示“执行任务的模型”“提出修改的模型”和预算上限。
优化模型是核心能力，不能与所有高级参数一起藏起来。
Prompt、工具协议、重试、并发、解析器、完整判定规则默认折叠。
仅启发式时明确显示“规则修复模式”，避免用户将其当作模型提出的改进；预期的启发式模式不应持续占用红色错误头条。

### Skill 与数据：业务内容优先

Skill 默认显示当前版本、主路由和子技能参数；哈希、内部 ID、父版本、审计详情收进历史/详情。
数据默认显示用户表达、预期子技能与工具参数；JSON 和划分高级参数按需展开。
导入有错误时明确选择“返回修复”或“剔除 N 条并发布”，不默认替用户选剔除无效案例。
当前 `dataset.js:815` 默认勾选剔除；虽有按钮数量提示，仍可减少这类隐含决策。

## 文案和结果语义

- “已完成”表示运行结束，不代表修改有效。
- 没有失败案例：显示“当前测试未发现可改进问题”，并说明覆盖范围，不表现为平台故障。
- 有候选但未提升：显示“未采用，当前版本保持不变”。
- 验证未完成：显示“证据不足”，突出缺什么证据。
- 相对改善与业务达标分开表达：例如“有改善，但仍有 3 条失败”；不能让 accept 暗示全部能力已通过。
- 页面使用 v2/v3 等可读版本号；内部 UUID 与完整哈希按需复制。

## 实施顺序

1. 修凭据、过期候选与日志状态同步，补必要浏览器回归。
2. 结论与主操作置顶，合并重复快照，模型配置与运行设置分层。
3. 增加单行目标、下一轮经验与应用后的继续/恢复入口。
4. 把真实纠正纳入回归集，再评估有上限的连续迭代。

暂不加入多候选并行、复杂 Agent 编排、自动改评分器、全自动采纳、权限系统或大规模数据分析页。
