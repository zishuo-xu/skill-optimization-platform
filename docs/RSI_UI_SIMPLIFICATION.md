# RSI 页面与配置简化

## 目标

围绕准备、执行、决定减少页面跳转与重复配置，保留 RSI 的独立验证、最终测试隔离、版本冻结、人工应用与恢复、取消及证据链。本轮不改变评分、fixture 匹配或优化算法，不自动采用候选。

## 页面与操作

- 工作台将 Skill、Prompt/模型设置、测试集集中为准备入口；基线属于运行阶段，不再与基础配置重复展示。
- 启动时默认使用当前版本，可明确选择已保存的草稿；不能默默选择最新草稿覆盖当前配置。未保存的编辑需要先保存。
- 一次确认后按顺序发布选定草稿，再冻结运行快照并启动。任何一步失败停止后续动作，显示失败阶段并说明已发布版本保留；同一选择重试复用运行幂等标识，修改选择后重新生成标识。
- 启动校验用户确认的 Skill、环境和数据集版本，防止在准备期间发生的版本切换被悄悄带入本轮。
- 结果页保留结论、独立验证样本/重复次数、回归及应用/恢复入口；技术快照与原始日志按需查看。

## 配置分层

- 核心配置：执行模型、Prompt、优化模型。Prompt 有直接编辑入口，默认简短预览，避免长文本占满页面。
- 按需评分：先看比较规则摘要；使用整体或字段级语义比较时显示评分模型，已配置的评分模型始终可以访问。
- 高级运行设置：上下文、步数、并发、时限及完整验收规则。固定的内部工具名只读，不再要求普通用户编辑。
- 标准 API 默认只填写地址、模型和密钥；自定义请求、Headers、流式等保留可达的高级入口和已配置摘要。不得因折叠字段而清空已有值。
- 环境草稿主操作统一为“保存并使用”，保留“保存草稿”；底层仍产生不可变版本。

## 验收与边界

仅面向 PC，不进行手机适配。使用隔离数据目录和 Demo 模型，不改变用户真实数据。

- 1280×800 浏览器验证了创建/保存配置草稿、语义评分按需显示、默认当前版本、显式选择草稿、发布并启动以及结果页，无横向溢出。
- 页面启动的 Demo 优化运行完成；验收结论为证据不足，未自动应用候选。这证明操作链路，不代表真实业务模型优化效果。
- 单元测试覆盖发布失败停止、部分发布后的重试、运行请求幂等标识复用、改选后更换标识，以及三类版本冲突拒绝。原有 RSI 回归继续执行。
- Skill 与环境发布沿用现有接口，不具备原子并发比较；本轮新增启动版本校验，可拒绝与用户选择不一致的运行快照，并未解决所有发布并发覆盖问题。
- 未调用外部付费模型，未重新验证远端网关或所有模型协议；本轮不修改其接入逻辑。
