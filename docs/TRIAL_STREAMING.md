# 试跑实时过程

## 目标与设计

点击试跑后即时显示实际执行事件，不用预设阶段或假进度替代模型执行。现有 JSON 试跑接口保持兼容；浏览器通过同一 POST 接口请求 NDJSON，接收 event、result、error 和 heartbeat 消息。只有 result 是最终评分结果，连接结束本身不表示成功。

执行、技能选择与读取、业务工具调用和评分继续共用原有试跑逻辑，不写入正式运行或指标。业务工具返回仍来自案例 fixture；自由输入使用占位返回，界面事件并不代表外部业务系统执行。事件发送前脱敏，不包含隐藏推理。

关闭抽屉中断客户端请求并通知服务端协作取消；正在进行的外部请求可能要等适配器返回或超时，不能承诺立即终止远程推理。网络中断保留已收到的事件并提示失败，不自动重试模型请求。

## 验收

- 慢速离线模型返回前，浏览器已经显示真实的模型调用开始事件。
- 实时显示后续技能、工具、评分事件，并最终显示原有评分结果。
- 数据集、自由输入、运行基线及候选版本入口使用一致链路。
- 验证错误、断流、关闭与再次运行；旧 JSON 接口保持兼容。
- 回归测试与浏览器验收完成后记录实际结果。

## 验证结果

- 工作区完整 Python 测试：546 passed，1 条既有 Starlette/httpx 弃用警告。
- 新增流式测试覆盖 JSON 兼容、事件/终态帧、执行阻塞期间事件可达、关闭取消、队列满时保留终态、超过 200 条事件的序号与保留窗口。
- 使用隔离数据目录与每次调用延迟 3 秒的离线模型，在真实浏览器点击数据集试跑：约 16 毫秒收到开始事件，约 3 秒已显示模型返回、技能选择与文件读取，此时约 9 秒的整个案例尚未结束；随后显示工具与评分完成及最终结果。
- 浏览器验证再次试跑、执行中关闭；过程截图：`output/playwright/trial-live-inflight.png`。未调用付费模型或外部业务工具，未改动现有项目数据。
