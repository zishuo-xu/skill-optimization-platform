# 最小改版：实施边界与验收

依据 2026-10-25 平台评审和用户选中的“最小改版”方案实施。
保留现有中文 SPA、五个项目页面、四个运行详情标签、数据库和单轮优化内核。

## 本批改动

1. 结果页先展示结论与下一步，再展示验证指标、案例变化；完整接受规则、成本及快照按需展开。
2. 概览统一状态和主操作；运行中可直接查看进度；配置重复快照收起。
3. 环境默认突出业务模型、优化模型和预算；Prompt、工具/上下文/并发等高级设置折叠。
4. 凭据接口与页面不暴露字面密钥；创建草稿、保存、发布和接入配置检查能保留已有凭据。
5. 过期候选前后端均阻止直接应用，检查 Skill/环境/数据集；保留历史结论并说明需复验。
6. 修复初始空日志收到 SSE 后不显示，以及运行终态与外层导航不同步。
7. 采用后提供继续下一轮和恢复原版本的明确入口，复用现有接口；不自动发起收费模型调用。
8. 数据集导入不默认剔除错误案例；普通业务内容优先展示，技术标识按需查看。

经验自动提炼、用户纠正写入回归集和自动连续多轮作为后续独立批次，不混入本次 UI 减法。

## 接口约定

- run view 提供 `applicability`：`current`、`stale_reasons`、`message`；`can_apply` 为当前评测条件和采用状态综合判定。
- 环境提供 `credential_status`：按 `model_config` / `optimizer_config` 分组，组内为字段名→是否已配置。
- 可公开 env:NAME / {env:NAME} 等明确引用；字面凭据只返回掩码，页面只显示已配置。
- 创建新环境携带同项目 `parent_id`，空值/掩码继承父环境对应凭据；无父版本时禁止存入掩码作为密钥。
- 连接测试可携带 `environment_id` 以服务端读取已有凭据，浏览器不需获得其内容。
- Skill 版本设为当前接口继续支持 `expected_current_version`，恢复入口必须校验当前仍是已采用候选。

## 验收

- 1200×800 桌面中结果主操作进入首屏；技术细节可展开，没有丢掉关键验证信息。
- 现有路由和导入/编辑/发布/应用/恢复路径可用；小屏无新增横向溢出。
- 先取空历史，再接收 SSE 事件，立即可见；终态更新后导航不再显示执行中。
- 改环境或数据集后原候选不可应用，正确条件下仍可应用；并发变化不能绕过检查。
- 凭据不进入 API 响应、页面正文或普通输入初始值；未修改密钥的草稿/接入配置检查仍保留原凭据。
- 有意义的后端回归和浏览器流程测试通过；浏览器测试使用数据副本和离线/本地假模型，不改原数据。

修改前源码及数据备份：`.run/minimal-redesign-20261025/before-source` 和 `before-data`。
